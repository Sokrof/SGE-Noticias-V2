INTRODUCCIÓN
El infinite scroll lanza un evento que se realizará cuando el usuario haga scroll a una
distancia específica del principio o final de la página.

La expresión asignada al evento ionInfinite se llama cuando el usuario alcance esa
distancia especificada. Cuando se terminen todas las tareas, hay que llamar a la función
complete() de la instancia de infinite scroll.

La documentación del infinite scroll está en la página:
https://ionicframework.com/docs/api/infinite-scroll

PREPARACIÓN
COMPONENTE
Para empezar a trabajar con el infinite scroll vamos a necesitar una página donde
usarlo. Creamos la página en la terminal:

ionic g page pages/InfiniteScroll --spec=false

export class InfiniteScrollPage implements OnInit {
data: any[] = Array(20);
constructor() { }
ngOnInit() {
}
loadData(event: any) {
console.log('Cargando siguientes ...');
setTimeout(() =>{
const nuevoArr = Array(20);
this.data.push( ...nuevoArr);
event.target.complete();
}, 1000 );
}
}

Explicación

setTimeout(() =>{: Vamos a simular una carga síncrona.
const nuevoArr = Array(20);: Creamos un nuevo array de 20 elementos.
this.data.push( ...nuevoArr);: Concatenamos el nuevo array al array

¿Pero qué pasa si nuestra colección de datos tiene 50 registros?
Para evitar el error que aparece al final de la colección, vamos a bloquear el infinite
scroll al llegar a los 50. En infinite-scroll.page.ts:
export class InfiniteScrollPage implements OnInit {
@ViewChild(IonInfiniteScroll,

{static:

false})

infiniteScroll: IonInfiniteScroll;
data: any[] = Array(20);
constructor() { }
ngOnInit() {
}
loadData(event: any) {
console.log('Cargando siguientes ...');
setTimeout(() =>{
if (this.data.length > 50) {
event.target.complete();
this.infiniteScroll.disabled = true;
return;
}

async loadMovies(event?: InfiniteScrollCustomEvent) {
const loading = await this.loadingCtrl.create({
message: 'Loading..',
spinner: 'bubbles'
});
await loading.present();
this.dataService.loadMovies(this.currentPage).subscribe(
{
next:

(res: ApiMoviesResult) => {

loading.dismiss();
this.movies.push(...res.results);
event?.target.complete();
if(event){
event.target.disabled =
res.total_pages === this.currentPage;
}
},
error: err => { console.error(err); },
complete: () => { console.log('Movies loaded!'); }
}
);
}
loadMore(event: InfiniteScrollCustomEvent) {
this.currentPage++;
this.loadMovies(event);
}
}
